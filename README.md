# AstroStepper

High precision stepper motor control library for Arduino (AVR), for astronomical tracking.

---------------------------------
OVERVIEW
---------------------------------
Deterministic timer-based control with high stability.

---------------------------------
FEATURES
---------------------------------
- DDS step generation
- Acceleration ramp
- Backlash compensation
- 16 kHz ISR
